# Multi-Blockchain

Multi-Blockchain subproject of the [LPNU-Metaverse-Project](../README.md).

## Overview

Multi-blockchain integration layer providing cross-chain identity and data interoperability for the LPNU Metaverse ecosystem.

## Project Structure

```
app/                # Application source code
contracts/          # Smart contracts for multiple blockchain platforms
tests/              # Test suite
docs/               # Documentation
```

## Quick start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run tests
pytest tests/ -v
```
